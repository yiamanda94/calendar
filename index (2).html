/** * 承辦人活動行事曆 — Google 試算表後端 * 貼到：試算表 →「擴充功能」→「Apps Script」，取代原本內容後存檔並部署。 */ // 填寫密碼：留空 '' 代表不用密碼；設定後，承辦人新增/修改/刪除時要輸入這組密碼 const KEY = ''; const TZ = 'Asia/Taipei'; const EV = '活動'; const ORG = '主辦單位'; const HEAD = ['id', '開始日期', '結束日期', '活動名稱', '地點', '主辦單位', '承辦人', '備註', '建立時間', '更新時間']; function sheet_(name, head) { const ss = SpreadsheetApp.getActiveSpreadsheet(); let s = ss.getSheetByName(name); if (!s) { s = ss.insertSheet(name); s.getRange(1, 1, 1, head.length).setValues([head]).setFontWeight('bold'); s.setFrozenRows(1); } if (name === EV) s.getRange('B:C').setNumberFormat('@'); return s; } // 日期統一成 yyyy-MM-dd（手動在試算表輸入 2026/9/24 也可以） function date_(v) { if (v instanceof Date) return Utilities.formatDate(v, TZ, 'yyyy-MM-dd'); const m = String(v || '').trim().match(/^(\d{2,4})[\/\-.](\d{1,2})[\/\-.](\d{1,2})$/); if (!m) return ''; let y = Number(m[1]); if (y < 1911) y += 1911; // 民國年也可以，例如 115/9/24 return y + '-' + ('0' + m[2]).slice(-2) + '-' + ('0' + m[3]).slice(-2); } function now_() { return Utilities.formatDate(new Date(), TZ, 'yyyy-MM-dd HH:mm'); } function out_(o) { return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); } function listEvents_() { const s = sheet_(EV, HEAD); const n = s.getLastRow() - 1; if (n < 1) return []; const rows = s.getRange(2, 1, n, HEAD.length).getValues(); const res = []; rows.forEach((r, i) => { if (!r[3]) return; if (!r[0]) { r[0] = Utilities.getUuid().slice(0, 8); s.getRange(i + 2, 1).setValue(r[0]); } // 直接在試算表新增的列自動補 id const date = date_(r[1]); if (!date) return; res.push({ id: String(r[0]), date: date, end: date_(r[2]), name: String(r[3]), place: String(r[4] || ''), org: String(r[5] || ''), person: String(r[6] || ''), note: String(r[7] || ''), updatedAt: r[9] instanceof Date ? Utilities.formatDate(r[9], TZ, 'yyyy-MM-dd HH:mm') : String(r[9] || '') }); }); return res; } function listOrgs_() { const s = sheet_(ORG, ['主辦單位名稱']); const n = s.getLastRow() - 1; if (n < 1) return []; return s.getRange(2, 1, n, 1).getValues().map(r => String(r[0]).trim()).filter(String); } function doGet(e) { try { return out_({ ok: true, needKey: KEY !== '', events: listEvents_(), orgs: listOrgs_() }); } catch (err) { return out_({ ok: false, error: String(err) }); } } function doPost(e) { const lock = LockService.getScriptLock(); try { const b = JSON.parse(e.postData.contents); if (KEY && b.key !== KEY) return out_({ ok: false, error: 'key' }); lock.waitLock(20000); const s = sheet_(EV, HEAD); if (b.action === 'save') { const v = b.event || {}; if (!v.date || !v.name || !v.org) return out_({ ok: false, error: '缺少必填欄位' }); const ids = s.getLastRow() > 1 ? s.getRange(2, 1, s.getLastRow() - 1, 1).getValues().map(r => String(r[0])) : []; const idx = v.id ? ids.indexOf(String(v.id)) : -1; const t = now_(); if (idx >= 0) { const row = idx + 2; const created = s.getRange(row, 9).getValue(); s.getRange(row, 1, 1, HEAD.length).setValues([[v.id, v.date, v.end || '', v.name, v.place || '', v.org, v.person || '', v.note || '', created || t, t]]); return out_({ ok: true, id: v.id }); } const id = Utilities.getUuid().slice(0, 8); s.appendRow([id, v.date, v.end || '', v.name, v.place || '', v.org, v.person || '', v.note || '', t, t]); return out_({ ok: true, id: id }); } if (b.action === 'delete') { const n = s.getLastRow() - 1; if (n > 0) { const ids = s.getRange(2, 1, n, 1).getValues().map(r => String(r[0])); const idx = ids.indexOf(String(b.id)); if (idx >= 0) s.deleteRow(idx + 2); } return out_({ ok: true }); } if (b.action === 'addOrg') { const name = String(b.name || '').trim(); if (!name) return out_({ ok: false, error: '名稱空白' }); if (listOrgs_().indexOf(name) < 0) sheet_(ORG, ['主辦單位名稱']).appendRow([name]); return out_({ ok: true }); } return out_({ ok: false, error: '未知動作' }); } catch (err) { return out_({ ok: false, error: String(err) }); } finally { try { lock.releaseLock(); } catch (x) {} } }
